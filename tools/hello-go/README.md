# hello-go

The Go example tool of this repo. It exists to exercise the build, version and release pipeline; copy its layout, then delete it once a real Go tool lands.

## Install

```sh
curl -fsSL https://raw.githubusercontent.com/what1f/ls-skills/main/install.sh | sh -s -- hello-go
```

## Usage

```sh
hello-go greet --name Ada
hello-go greet --name Ada --format json
hello-go version
```
