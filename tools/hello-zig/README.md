# hello-zig

The Zig example tool of this repo. It exists to exercise the build, version and release pipeline; copy its layout, then delete it once a real Zig tool lands.

## Install

```sh
curl -fsSL https://raw.githubusercontent.com/what1f/ls-skills/main/install.sh | sh -s -- hello-zig
```

## Usage

```sh
hello-zig greet --name Ada
hello-zig greet --name Ada --format json
hello-zig version
```
